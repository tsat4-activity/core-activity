# โครงสร้างทีมของแต่ละกิจกรรม (ผู้ใช้กำหนด 2026-10-30)

**ทุกกิจกรรมเริ่มด้วย ประธาน · รองประธาน · ที่ปรึกษา · ผู้ประสานงาน** แล้วตามด้วยบทบาทของกิจกรรมนั้นเอง (`ACT_TEAM_ROLES` ใน `public/js/act.js`)
ตารางทีม: `mt_<กิจกรรม>_team` = role + `unit` (ทีมย่อย) + หน่วยงาน / กลุ่มตรวจ / พื้นที่ · role ที่ฐานรับอยู่ใน role check ของ `scripts/act-sql.js` · สิทธิ์ใน `server/modules/act/common.js` `accessOf`

| role | ป้าย | สิทธิ์ |
|---|---|---|
| `chairman` / `vice` | ประธาน / รองประธาน | คณะกรรมการกลาง หรือของทีมตรวจประเมิน = Committee Audit + จัดการ Issue · ประธานทีมอื่นนำทีมของตัวเอง |
| `advisor` | ที่ปรึกษา | ดูอย่างเดียว |
| `admin` | ผู้ประสานงาน | ของคณะกรรมการกลาง (unit ว่าง) = ดูแล Setting ของกิจกรรมปีนั้น · ผู้ประสานงานทีมย่อยไม่ได้สิทธิ์ Setting |
| `member` | สมาชิก | สมาชิกทีมย่อย (unit) หรือตัวแทนหน่วยงาน (department) |

## กติกา 5ส (ผู้ใช้กำหนด 2026-10-30)

- **ผู้รับผิดชอบพื้นที่**: Self Audit พื้นที่ตัวเอง 25 ข้อ ทุกเดือน ก่อนวันที่ 10 (`self_audit_due_day` = 10)
- **ผู้ตรวจประเมิน**: Committee Audit พื้นที่ทุก 3 เดือน ตามแผนตรวจ (Setting → แผนตรวจ) · ข้อที่ได้**ต่ำกว่า 3** ต้องเปิด Issue พร้อมรูป 16:9 และรายละเอียด (`issue_score` = 3)
- **Action**: ผู้รับผิดชอบพื้นที่แก้ให้เสร็จ **ก่อนตรวจครั้งถัดไป 15 วัน** (`issue_due_days_before_next` = 15) · ตรวจรอบถัดไปได้ 3 ขึ้นไปและมี Action ครบ = ปิด Issue
- ร่างก่อนหน้า (role `standard` / `academic` / `pr`) ถูกย้ายเป็นสมาชิกของทีมนั้นเองเมื่อรัน `db/act/5s.sql`
